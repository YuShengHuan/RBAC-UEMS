# RBAC-UEMS
针对目前高校实验教学管理存在权限管控单一、跨系统数据壁垒突出和功能智能化程度低的问题，本文从高校实验教学管理的实际需求出发，设计并实现了一个基于RBAC模型的实验教学数字化管理系统。系统采用B/S模式及MVC架构，选用SpringBoot3+Vue3作为核心技术栈，MySQL作为数据存储引擎，其中主要模块包含权限管理、数据互通、实验项目管理、实验报告管理。在权限管理部分，严格按RBAC模型实现精细化的“用户-角色-权限”映射；在数据互通部分用数据解析方法整合教务系统中异构数据，以此来解决跨系统数据互通难题；在实验项目管理部分提供实验项目的创建、修改、删除等基本操作；在实验报告管理部分设计全生命周期流程，并引入TF-IDF算法+余弦相似度公式对实验报告相似度进行精准检测，同时支持在线预览。
