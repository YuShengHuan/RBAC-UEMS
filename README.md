# 基于RBAC高校实验教学数字化管理系统 

## 项目概述

本项目面向高校实验教学管理现存痛点：权限划分笼统、教务与实验系统数据割裂、业务智能化不足，基于RBAC权限模型打造一套前后端分离数字化实验教学管理平台。整体采用B/S + MVC架构，后端SpringBoot3、前端Vue3+TS，搭配MySQL持久化存储、Redis缓存优化性能；系统区分超级管理员、分院管理员、教师、学生四级角色，完成教务异构数据对接、实验项目统筹、实验报告全流程管理，融入TF-IDF+余弦相似度查重、Word转PDF在线预览、批量Excel导入导出、登录安全校验等实用能力，打通实验教学从排课、实操、提交报告到批阅归档完整业务闭环，提升院校实验教学数字化管理效率。

## 技术栈清单

### 后端

- 核心框架：SpringBoot3（Java17）
- 安全认证：Spring Security + JWT令牌 + AOP切面权限校验
- 持久层：MyBatis、MySQL 8.0（InnoDB、utf8mb4）
- 缓存加速：Redis（权限缓存、会话缓存）
- 文件处理：POI（Excel解析导入导出）、LibreOffice（Word转PDF预览）
- 文本算法：TF-IDF + 余弦相似度（实验报告查重）

### 前端

- 基础框架：Vue3 + TypeScript（组合式API）
- 路由管理：VueRouter（路由权限拦截）
- 全局状态：Pinia
- UI组件库：Element Plus
- 文档预览：VuePdfEmbed
- 构建工具：Vite

## 系统角色与权限划分

系统基于RBAC三层权限架构（用户—角色—权限），严格遵循最小权限原则，四类角色权责完全隔离：

| 角色       | 编码  | 核心权限范围                                         |
| ---------- | ----- | ---------------------------------------------------- |
| 超级管理员 | R0000 | 全局系统配置、角色权限分配、全院用户/组织数据统筹    |
| 分院管理员 | A1000 | 本院师生、班级、实验资源管理，无全局权限配置权限     |
| 教师       | T2000 | 授课实验编排、课表导入、报告批阅、报告查重、模板维护 |
| 学生       | S3000 | 查看课表、下载实验模板、上传实验报告、查阅批阅成绩   |

## 系统整体模块拆分

1. **权限管控模块（RBAC核心）** 用户管理、角色创建与分配、接口权限绑定、权限缓存刷新、登录安全防护（图形点选验证码、JWT双Token续期）；
2. **基础组织模块** 学院、专业、班级三级架构维护，为用户归属、实验资源分配提供底层数据支撑；
3. **教务数据互通模块** 教务系统异构Excel数据解析导入、自定义模板批量导入、课表/项目数据导出，消除跨系统数据孤岛；
4. **实验教学业务模块** 实验课程排期管理、实验室资源调度、实验项目创建维护；
5. **实验报告全生命周期模块** 报告模板下发、学生提交、在线批阅、相似度查重、PDF在线预览、成绩归档；

## 系统架构设计

整体分为四层分层架构，解耦清晰，便于迭代扩展：

1. **前端展示层** Vue3页面渲染、路由权限拦截、文件上传下载、PDF预览、交互表单；
2. **安全认证层** 验证码校验、JWT签发与校验、Token无感续期、AOP接口权限拦截、敏感密码加密存储；
3. **业务服务层** 用户、权限、组织、实验排课、报告批阅、文本查重、Excel解析等核心业务逻辑；
4. **数据存储层** MySQL：业务数据持久化，建立合理索引保证查询效率； Redis：高频权限数据、会话信息缓存，减轻数据库压力。

## 数据库设计思路

选用MySQL8.0，字符集utf8mb4，存储引擎InnoDB支持事务：

1. 遵循第三范式，拆分数据表降低冗余，主键、外键约束保障数据一致性；
2. 核心数据表分类：
   - 权限体系：用户表、角色表、权限表、用户角色关联表、角色权限关联表；
   - 组织架构：学院表、专业表、班级表；
   - 实验业务：实验室、实验课程、课程排期、实验项目、实验报告表；
3. 统一设置创建时间、更新时间字段，追踪数据变更记录；高频查询字段建立索引优化响应速度。

## 核心功能详细实现

### 一、登录与全链路安全拦截

1. **前端防护** 登录搭载文字点选式图形验证码，抵御脚本批量撞库；VueRouter全局守卫依据用户权限动态渲染路由，无权限页面直接跳转404；
2. **后端双层权限校验**

- JWT过滤器：校验访问令牌有效性，过期则凭借刷新令牌自动续期，失效强制退回登录页；
- AOP切面拦截：请求进入接口前读取Redis内角色权限列表，比对接口所需权限编码，未授权直接拒绝访问；

### 二、管理员端核心功能

1. 基础数据CRUD：用户增删改查、院系班级维护、实验室信息管理，分页条件检索适配海量数据场景；
2. 动态权限分配：超级管理员可勾选批量分配权限，系统清空原有角色权限、批量写入新关联关系，同步更新Redis缓存，权限即时生效；
3. 全院实验数据统筹管控，分院管理员仅限定本院数据操作范围。

### 三、教师端核心业务

1. **三种课表创建方式** 手动逐条录入、教务系统导出Excel异构数据解析导入、通用模板批量导入，系统自动校验实验室时间资源冲突；
2. 实验项目批量创建：单条新建 + Excel模板批量导入两种模式；
3. **实验报告批阅与查重** 查重范围限定同班同实验项目，采用TF-IDF提取文本特征向量，结合余弦相似度计算文本重复率，相似度降序展示相似报告；
4. **Word在线预览** 后端调用LibreOffice将docx转为PDF，以字节流返回前端，通过PDF组件直接在线浏览，无需本地下载打开。

### 四、学生端核心业务

查看本班实验排课计划、下载实验指导模板、按时上传实验报告、查看教师批阅评语与最终成绩。

## 系统测试指标

### 1. 功能测试

逐一对四类角色全部业务流程进行用例测试：权限访问校验、数据导入导出、报告提交批阅、查重预览功能均可稳定运行，权限隔离生效，越权访问全部拦截。

### 2. 非功能性指标

- 安全性：密码加密存储、接口权限拦截、验证码防刷、Token认证完整规避越权、爬虫攻击；
- 响应性能：常规页面跳转、数据查询响应 ≤ 1s；批量导入、文本查重等复杂运算 ≤ 10s；支持200人并发稳定访问；
- 易用性：四类角色差异化UI界面，操作流程贴合师生日常使用习惯，错误提示清晰易懂；
- 扩展性：模块化低耦合设计，后续可新增实训考核、设备预约等功能无缝接入。

## 项目总结与后续展望

### 总结

本系统依托RBAC精细化权限体系解决了高校实验教学多角色权限混乱问题，通过Excel异构数据解析打通教务数据壁垒，围绕实验报告搭建完整数字化流程，引入文本相似度检测规范学术作风，分层架构与缓存设计兼顾系统性能与可维护性，切实解决传统线下实验管理效率低下、数据分散的痛点，为院校实验教学数字化建设提供落地参考方案。

### 展望

1. 接入实验设备预约、实训耗材申领模块，拓展实验资源全生命周期管理；
2. 接入AI批改辅助功能，对简答类实验内容进行初步智能评判，减轻教师批阅压力；
3. 新增数据可视化大屏，统计实验开课频次、报告完成率、查重违规数据等教学运营指标；
4. 适配移动端页面，支持师生手机端随时查看课表与批阅信息。

## 部署运行

### 环境要求

JDK 17、Maven 3.6+、MySQL 8.0、Redis 5.0+、Node 16+

### 启动步骤

1. 后端：导入SQL脚本初始化数据库，修改yml数据库、Redis连接配置，Maven打包运行；
2. 前端：进入前端目录安装依赖 `npm install`，启动开发环境 `npm run dev`；
3. 部署：前后端分离打包，Nginx反向代理部署上线。
